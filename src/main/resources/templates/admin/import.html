第 1 步：下载模板并填写

⬇ 下载 CSV 模板

用 Excel / WPS 打开模板填写，完成后“另存为 CSV”格式。列说明：

名称必填
SKU可选。与已有商品相同则更新该商品，否则新建；留空自动生成
分类可选。填写分类名称，不存在会自动创建
售价必填，例如 59.9
原价可选，显示为划线价
库存可选，整数；新商品默认 0
状态可选：上架 / 下架 / 草稿；留空使用下方的默认状态
图片可选，图片网址，多张用 | 分隔，第一张为主图
描述可选

第 2 步：上传文件

自动识别 UTF-8 和 GBK 编码，Excel 直接保存的文件也可以导入。
